# リフォーム現地調査 ヒアリング項目 たたき台 v4.0

> **v3 → v4 の変更点（御社の現行チェックシート9枚の実項目を反映）**
> - **部位構成を「現行シート」に確定**：v3の抽象的な「8工種」を、御社の実シートに合わせて **水回り5＋内装3＝8部位** に置き換え。外装系（外壁・屋根・防水・給湯機の単独）は現行シート未整備のため **「今後追加の枠」** として保持。
> - **各部位に"実項目"を投入**：現行シートから抽出した **実測・仕様確認／ヒアリング／写真撮影箇所／トークスクリプト参照／判断めやす** を第2部の各部位に反映。
> - **共通シートを統合**：「現地調査チェックシート（全体・共通）」の項目を **第3部（建物・共通現況）／第4部（段取り・記録）** に統合。
> - **2大前提は維持**：①新人でも漏れなく ②対象外でもアップセル確認（設置年数・劣化・型番の3点）。内装系は"型番"が馴染まないため、アップセル診断3点を **経過年数／劣化／現況仕様** に読み替えて適用。
>
> ※ v4は「御社の実シート項目」で肉付けした版です。数値のめやす・見本写真・スクリプト本文は、既存スプレッドシートや御社ノウハウで引き続き精度を上げていく前提です。

---

## 設計思想（会議＋2大前提）

1. **新人ガイド型**：システムが順に指示。各項目に"判断の助け（4点セット）"が付く。
2. **全部位スキャン**：8部位すべてを確認済みにしないと調査完了不可。
3. **対象外でもアップセル診断**：対象外の部位でも「年数・劣化・型番（内装は現況仕様）」の3点は必ず記録 → 追加提案の起点を消さない。
4. **写真必須／サマリーで最終チェック**。
5. まずチェックシート完成 → 見積もり・製品提案は次段階。

## 各項目に付く「新人ガイド4点セット」（前提①の中身）

第1〜4部の各項目には、システム上で以下が表示される想定です。中身は今回、現行シートから抽出した実例で一部を埋めています（未記載は既存スプレッドシート／御社ノウハウで拡充）。

- **判断のめやす**：例）UB「（B＋C）−A が 510mm より大きいと窓と浴槽が干渉」／キッチン「ガス警報機が天井近く＝都市ガス、床近く＝プロパン」
- **見本写真**：良好／経年／要注意 の3段階サンプル画像
- **用語ミニ解説**：例）「在来浴室＝タイル張りの現場施工／UB＝工場製の一体型」「真壁＝柱が見える壁／大壁＝柱を隠す壁」「聚楽＝和室系の塗壁」
- **質問文（トークスクリプト）**：新人がそのままお客様に聞ける言い回し（トイレ・UB・洗面・キッチン等はシートに参照リンクあり）

### 同時施工の相性ヒント（新人が思いつかない提案を後押し）
- **外壁＋屋根＋防水**：足場を共有できるため、まとめると足場代が一度で済みお得。
- **トイレ／洗面交換＋内装（クロス・床）**：既存撤去で床壁が傷むので同時施工が自然。
- **浴室（UB交換）＋給湯機**：追い焚き・湯量の連携。同時更新で効率的。
- **キッチン交換＋給排水・電気の見直し**：容量／配管を整える好機。
- **水回り（キッチン・浴室・洗面・トイレ）まとめて**：配管・工期を集約して効率化。
- **和室→洋室／間仕切り＋クロス**：内装が連続するため同時施工でロス減。
